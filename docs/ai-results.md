# PhotoCraft result layers and comparison

Result-layer and comparison contracts have native automated and screenshot evidence. Overall Phase K remains PARTIAL: provider regeneration, full corpus regression and hardware qualification are pending. This document does not claim a functioning image model or successful AI generation.

Open **Window → AI Results**. An imported proposed image becomes a new raster layer with an editable selection mask, visibility and opacity. Accept marks the proposal accepted and keeps it editable. Reject removes it as an Undo transaction. Importing a replacement keeps the previous proposal in the document, hidden, and inserts a new record rather than rewriting old attribution. Generation and provider-based regeneration are a separate phase.

The import dialog uses the selection's rectangular bounds, or the whole canvas when there is no selection. The incoming image must have exactly those dimensions. The selection's actual coverage becomes a bounded editable mask; pixels outside it remain unchanged in the composite. Input is limited to PNG, JPEG or WebP, 48 MiB encoded, 4096 pixels per side, 16,777,216 pixels and 256 MiB decoder allocation. Truncated or additional-frame results are rejected. Embedded ICC profiles must parse and match the image channels; missing profiles use the application's existing mode defaults. Result pixels are converted into RGB, Grayscale, CMYK or Lab documents at 8/16/32-bit depth. Indexed, Bitmap, Duotone and Multichannel imports return an error without editing the document. Convert a copy before importing into those modes. A result is inserted at the root top, preventing inherited group blending or duplicate compositing beneath source layers.

Imports use the existing background-job machinery in native applications, with cancellation checks around bounded decode and preparation. Jobs lock their originating document and reject stale application. Tests and browser builds follow the existing inline job behavior. No network call occurs when importing, accepting, rejecting or comparing results.

Each result carries versioned native provenance: origin, proposed/accepted state, claimed provider/model for imports, timestamp, edit recipe, the encoded result's BLAKE3 hash, and an import-time hash of the current composited region, selection coverage and composite profile. Imported attribution is not verified provider identity, and the import-time input hash does not claim to identify an earlier external model request. The result hash describes the original imported bytes; subsequent layer edits do not rewrite that history.

The `.pcraft` format preserves typed provenance with defaults for older documents and validation on read and write. Other formats cannot be assumed to preserve it. In particular, PSD/PSB preserve the ordinary result pixels and layer controls, not this native metadata. Export warnings have been tested for PSD/PSB/PNG and native roundtrip. The pinned corpus was fetched and verified in isolation; the full corpus regression remains a required combined gate after the guidance/provider document changes settle.

Enable **Compare on canvas** for vertical split, horizontal split, overlay, full before or full after. **Before** means the current document with the selected result hidden. Other document changes are reflected in both views; it is not a frozen historical screenshot. The viewer reuses the document compositor, monitor conversion and canvas transform. Divider motion, pan, zoom and rotation reuse cached images; changed document content, selected result or display conversion invalidates them. Four display caches are retained at most and inactive comparison releases its images. Cold composition and warm divider interaction are measured separately.

While comparison is active, native canvas dragging adjusts the divider and cannot paint. Document-coordinate `ui.pointer` paint events are suppressed; automation can move the divider through `ui.set.aiResults.position` or native screen input. Wheel/scrollbar navigation, Space and middle-button panning remain available. **B** shows before, **A** shows after, **S** returns to vertical split, and **Esc** ends comparison when text input is not focused. Use the ordinary mask editor after leaving comparison. Finish pending crop, text, transform or floating-selection edits before comparing committed artwork.

The source, imported-image tests, before/after fixtures and timing example use synthetic content. They provide transaction and viewer evidence, never a model-quality claim. Real provider integration, guidance and authorization still require their own gates. No external pixels or source artwork have been transmitted in this implementation task.
